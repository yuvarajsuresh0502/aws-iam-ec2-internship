AWS IAM & EC2 Internship Project

Cloud Computing | AWS | Linux | Web Hosting

About This Project

This project demonstrates how to configure AWS IAM, launch a Linux EC2 instance, apply network security rules, and deploy a basic website using Apache.

AWS Services Used

  • IAM — Identity and access management
  • EC2 — Virtual Linux server
  • Security Groups — Network traffic control
  • EBS — Persistent block storage
  • Apache HTTP Server — Website hosting

Security Best Practices

  • Follow the principle of least privilege.
  • Restrict SSH access to an approved IP address.
  • Allow HTTP traffic for public website access.
  • Keep private keys and AWS credentials secure.

Project Outcome

A Linux web server hosted on Amazon EC2 and serving this HTML page to visitors over HTTP.
